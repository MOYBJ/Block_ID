# Block ID

Minecraft 1.19.2 方块ID管理与 WorldEdit 指令生成客户端模组（Forge 版）。

## 功能

- 🎯 方块ID快速复制（多选，逗号分隔）
- ⚡ WorldEdit 指令一键生成（`//set`、`//replace`）
- 🔧 方块状态属性可视化设置（朝向、半层、含水等）
- 📊 放置率权重滑块，自动归一化 100%
- 🔍 智能搜索（中文名 / 英文ID / 拼音首字母）
- ⭐ 常用方块自动收集与管理
- 🌍 9种语言支持

## 版本

当前版本：**2.1.1-Beta**

支持游戏版本：Minecraft 1.19.2
支持加载器：Forge 43+

## 前置模组

无必需前置，下载即可使用。

- 可选：WorldEdit —— 安装后生成的 `//set` / `//replace` 指令可直接粘贴执行；
  未安装时模组功能完全不受影响，指令同样会复制到剪贴板，只是需要在聊天栏手动粘贴。

## 使用

- 按 **G** 打开管理界面
- 按 **C** 复制手持方块ID
